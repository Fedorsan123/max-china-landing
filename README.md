# MChina — сайт агентства поступления в вузы Китая

Публичная версия сайта для GitHub Pages: https://fedorsan123.github.io/max-china-landing/

Страница собрана одним файлом: `index.html`. Внутри всё — стили, скрипты,
шрифты и фотография. Сервер и интернет-зависимости не нужны.

## Что это

Версия на согласование. Страница закрыта от поисковиков (`robots: noindex`),
форма заявки пока ничего не отправляет. Цены указаны в юанях.

## Как обновить

Исходники живут в рабочем репозитории проекта, в `mchina/src/`.
Сборка сразу в эту папку: `node tools/build-mchina.js --site`,
затем коммит и пуш этой папки.

Править `index.html` напрямую не нужно — при следующей сборке правки пропадут.

Папка `k-7c3f9a2e58/` — отдельное личное приложение, к сайту не относится.

# MAX-China — лендинг

Черновик посадочной страницы направления «Поступление в Китай».

Страница собрана одним файлом: `index.html`. Всё внутри — стили, скрипт
и фотография. Внешних зависимостей нет, кроме шрифтов Google Fonts.

## Что это

Прототип на согласовании. Цены, реквизиты ИП и юридические тексты
не заполнены — на их месте пометки в квадратных скобках.

Страница закрыта от поисковиков через `robots: noindex`. Снять перед запуском.

## Как обновить

Исходник живёт в рабочем репозитории проекта, в `content/prototype/landing.src.html`.
Сборка: `node tools/build-site.js`, затем коммит и пуш этой папки.

Править `index.html` напрямую не нужно — при следующей сборке правки пропадут.

НАСТРОЙКА ХРАНИЛИЩА ДЛЯ ПРИЛОЖЕНИЯ «КАРКАС ГОДА»
=================================================

Это нужно сделать один раз, чтобы телефон и компьютер видели одни и те же
галочки. Без этого приложение работает, но данные лежат только на том
устройстве, где ты их поставил.

ШАГ 1. Завести проект
---------------------
Зайди на supabase.com, зарегистрируйся (почта и пароль, карта не нужна),
создай новый проект. Регион выбирай ближайший. Проект поднимется за пару минут.

ШАГ 2. Создать таблицу
----------------------
Открой раздел SQL Editor, вставь текст ниже целиком и нажми Run.


create table if not exists public.karkas (
  id         text primary key,
  payload    jsonb not null,
  updated_at timestamptz not null default now()
);

alter table public.karkas enable row level security;

create policy "karkas_select" on public.karkas
  for select to anon using (true);

create policy "karkas_insert" on public.karkas
  for insert to anon with check (true);

create policy "karkas_update" on public.karkas
  for update to anon using (true) with check (true);


ШАГ 3. Взять два значения
-------------------------
Раздел Settings → API. Понадобятся:

  Project URL      — вида https://xxxxxxxx.supabase.co
  anon public key  — длинная строка, начинается на eyJ

ШАГ 4. Вписать в приложение
---------------------------
Открой приложение → Настройки → «Синхронизация между устройствами».
Вставь оба значения, придумай код пространства (любое слово, например
moy-karkas-2026) и нажми «Сохранить и подключить».

На втором устройстве введи ровно те же три значения. Данные подтянутся сами.


ЧТО ВАЖНО ПОНИМАТЬ ПРО БЕЗОПАСНОСТЬ
-----------------------------------
Ключ anon по своей природе публичный: он лежит в браузере и виден тому, кто
откроет твою страницу и заглянет в её настройки. Правила выше разрешают этому
ключу читать и писать таблицу karkas. Значит, защита здесь держится на том,
что ссылку на страницу и код пространства знаешь только ты.

Для личного расписания это нормально: там нет ни денег, ни паролей, ни данных
клиентов. Но не клади в это приложение ничего, что нельзя показывать —
ни телефонов родителей, ни сумм, ни условий с головным офисом.

Если однажды понадобится настоящая защита, решение известное: включить в
Supabase вход по почте и разрешить доступ только своему пользователю. Это
отдельная работа, скажешь — сделаем.
